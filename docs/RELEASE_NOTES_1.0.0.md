# Rim Languages — Individual Learning 1.0.0

Première version stable pour RimWorld 1.6, complément de Cybranian — Rim Languages.

- Connaissances et progression propres à chaque pion, persistantes après sauvegarde, recrutement et caravane ; onglet Langues et outils développeur individuels.
- Lecture, apprentissage auprès des prisonniers et transmission automatique dans les conversations ordinaires, sans modifier les priorités sociales.
- Restrictions et facteurs sociaux d'après les pions concernés ; affichage des factions sans niveaux collectifs.
- Avec Biotech : apprentissage des nouveaux bébés pendant nourrissage et jeux, sans bloquer l'éducation vanilla. Avec Ideology : progression personnelle associée aux préceptes linguistiques du parent.
- Livres, langues, dialectes, configuration initiale et difficulté de Cybranian conservés. Ajout à une sauvegarde existante pris en charge avec initialisation minimale documentée.

Installer le ZIP **RimLanguages-IndividualLearning-1.0.0.zip**, et non les archives automatiques des sources GitHub. Extraire son dossier dans `<RimWorld>/Mods`. Ordre relatif : Harmony → Cybranian → Individual Learning. Aucun DLC obligatoire, aucune dépendance à GateRim.

Comportements identiques à la 0.17.0 validée par l'utilisateur ; version, preview et empaquetage finalisés. Reconstruction et 277 assertions hors jeu réussies ; neuf fichiers d'archive contrôlés. Les tests en jeu ont été rapportés par l'utilisateur, aucun moteur exécuté par l'agent. Schéma de sauvegarde 1 conservé ; compatibilité avec d'autres mods non exhaustive.

---

First stable release for RimWorld 1.6. Requires Harmony and Cybranian — Rim Languages, followed by this addon. DLC features are optional; GateRim is not required.

Persistent per-pawn languages and dialects, a compact Languages tab, individual learning from books, prisoner lessons and ordinary conversations. Prisoner interactions, trade, communications and social factors use personal knowledge. Optional Biotech infant learning preserves vanilla education; optional Ideology events reuse Cybranian's language-learning precepts.

Download **RimLanguages-IndividualLearning-1.0.0.zip**, extract the mod folder into `<RimWorld>/Mods`, then restart the game. GitHub's automatic source archives do not contain the compiled mod DLL. Existing Cybranian saves use the documented minimal initialization policy; save schema remains 1. Collective data remains active internally for compatibility and fallbacks.

Gameplay matches the user-tested 0.17.0. Build, 277 outside-game assertions and all nine archive contents checked. In-game validation was reported by the user; the agent did not run RimWorld. Other-mod compatibility is not exhaustive. Steam Workshop publication is handled separately.
