# Installer Individual Learning

Version : lire le champ Mod Version dans RimSort ou modVersion dans About/About.xml.

1. Installer RimWorld 1.6 ou 1.7, Harmony et Cybranian — Rim Languages. La compatibilité 1.7 est confirmée sur la branche instable par l'utilisateur ; les prochaines builds peuvent nécessiter de nouvelles adaptations.
2. Fermer RimWorld avant de remplacer une ancienne copie du complément.
3. Extraire le dossier RimLanguages-IndividualLearning de cette archive dans le dossier Mods du jeu. About et 1.6 doivent être directement dans ce dossier, sans deuxième dossier imbriqué.
4. Activer les mods dans cet ordre relatif : Harmony, Cybranian, puis Individual Learning. Redémarrer le jeu après remplacement de la DLL.
5. Ouvrir Langues sur un pion pour consulter ses niveaux. La difficulté se règle dans Cybranian ; le complément possède une case d'activation de transmission automatique.

Pour une partie ayant déjà Cybranian, charger une copie de la sauvegarde puis sauvegarder sous un nouveau nom. Les pions sans registre reçoivent seulement la langue et le dialecte de leur faction observée ; les connaissances personnelles existantes sont conservées. L'origine d'un colon recruté avant l'installation ne peut pas être reconstituée. Le retrait du complément n'a pas de migration garantie.

Aucun DLC obligatoire. Biotech est nécessaire aux parcours de bébés ; Ideology et un précepte linguistique du parent sont nécessaires aux pensées correspondantes. GateRim n'est pas une dépendance.

Sources, limites et signalements : https://github.com/Diablood/RimLanguages-IndividualLearning

## English installation

Install RimWorld 1.6 or 1.7, Harmony and Cybranian — Rim Languages. Version 1.7 compatibility is user-tested on the unstable branch; future builds may need further updates. Close the game, extract the RimLanguages-IndividualLearning folder into the game's Mods directory, then enable Harmony, Cybranian and this addon in that relative order. Restart after replacing the DLL. About and 1.6 must be directly inside the mod folder; LoadFolders.xml routes both game versions to the same assembly folder.

The pawn's Languages tab displays individual levels. Learning difficulty is controlled by Cybranian; the addon has an automatic transmission toggle. Try existing saves on a copy. Missing records receive only the observed faction's native language and dialect; existing personal records are retained. Historical origins of previously recruited pawns cannot be reconstructed. Removal has no guaranteed migration.

No mandatory DLC or GateRim dependency. Baby learning requires Biotech; linguistic thoughts require Ideology and a suitable Cybranian precept. This archive contains only the addon, not its dependencies.
